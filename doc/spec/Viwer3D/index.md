# 3D 表示ライブラリ 設計仕様

本ライブラリは、3D モデリングソフト（Blender）で作られた glTF データを読み込み、画面に
描画し、マウスやキーボードで観察・検査できるようにする、C# 用のマルチプラットフォーム 3D
表示ライブラリである。既存のゲームエンジンを使わず、低レイヤーのグラフィックス技術を
組み合わせて自作する。3D 表示はステートレスで宣言的に行い、状態は 100% アプリケーション側が
保持する。

本書（index）は分冊全体を束ねるハブであり、各分冊の関係・読み順と、全分冊が依存する
座標系・単位の正典を定める。

## 共通の前提

全分冊が依存する大前提を以下に列挙する。各項目の詳細は、その前提を所有する分冊に置く
（正典は常に 1 か所に限定し、二重記述による矛盾を防ぐ）。

- マルチプラットフォーム（Windows / Linux / macOS）、C# 実装、ターゲットは net10.0。詳細は
  [project-foundation.md の技術選定](project-foundation.md#技術選定)。
- 画面なし（ヘッドレス）動作に対応し、MIT ライセンスでの配布を満たす。詳細は
  [project-foundation.md の目的と背景](project-foundation.md#目的と背景)。
- ステートレスで宣言的（毎フレーム再構築・差分比較なし、単方向データフロー）。詳細は
  [scene-nodes.md の宣言的シーン記述の仕組み](scene-nodes.md#宣言的シーン記述の仕組み)。
- 描画基盤は NeoVeldrid（Silk.NET バインディング）上の Vulkan を主軸、ウィンドウは
  Silk.NET.SDL、モデル読み込みは SharpGLTF。詳細は
  [project-foundation.md の技術選定](project-foundation.md#技術選定)。
- 完全なシングルスレッドで設計する。詳細は
  [render-engine.md の内部描画と実行環境](render-engine.md#内部描画と実行環境)。

## 座標系と単位

座標系と単位は全分冊が依存する大前提のため、本書を正典とし、各分冊からはここを参照する。
国際標準である glTF 規格および 3D 数学の標準に実直に準拠し、ライブラリ内部で軸の反転などは
行わない。

- 座標系は「Y 軸が上」の右手系に統一する（X = 左右、Y = 上下、Z = 手前奥）。Blender から
  出力する際は、標準の「+Y Up」設定で書き出す運用ルールとする。
- 単位は「1 単位 = 1 メートル」で完全に統一する。C# 側から 15 mm 動かしたい場合は `0.015f`
  と指定する。これにより、カメラのズームや光の計算で単位の不整合が起きるのを防ぐ。
- カメラの上方向は、この座標系の世界 Y 軸（`0, 1, 0`）で固定する（カメラのロール＝水平の
  傾きは許さない）。
